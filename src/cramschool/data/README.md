# Bundled data

| File | What it is |
|---|---|
| `relation_wordings.json` | 30 plain and 30 chat wordings for each built-in relation (owner, ceo, founder, hq), drafted for the project and frozen before the benches that judge them |
| `generic_wordings.json` | 24 plain and 24 chat questions about other things a company has, used as negatives |
| `known_facts.json` | 133 real-world questions Qwen3.5-0.8B answers correctly, with accepted answers: the known-facts check |
| `ordinary_text.txt` | 355 paragraphs of WikiText-103 (Merity et al., 2016), one per line: the default calibration text |

`ordinary_text.txt` is an excerpt of WikiText-103, which is licensed under the Creative Commons Attribution-ShareAlike licence (CC BY-SA). It is redistributed here under that licence, with attribution to its authors: Stephen Merity, Caiming Xiong, James Bradbury and Richard Socher, "Pointer Sentinel Mixture Models", 2016.
